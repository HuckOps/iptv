# IPTV 直播源

自动拨测维护的直播源列表，可直接用于播放器。

## 直播源地址

| 区域 | m3u8 文件 |
|---|---|
| 中国合规 | `live_cn.m3u` |
| 全球 | `live_global.m3u` |

- 仓库根目录直接获取：`live_cn.m3u` / `live_global.m3u`
- 或通过 raw 链接订阅（将仓库地址替换为你的 fork）：
  - `https://raw.githubusercontent.com/HuckOps/iptv/main/live_cn.m3u`
  - `https://raw.githubusercontent.com/HuckOps/iptv/main/live_global.m3u`

源每 4 小时自动更新一次。
